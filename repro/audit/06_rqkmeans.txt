=== notes
  The 4th code is not bounded by 512: codes are written as plain text "c0 c1 c2 dup"
  (process4gr.py) and tokenized with the mT5 tokenizer; decoding is constrained by a Trie
  built from the existing code strings (recall/GR/train.py build_trie). So dedup values
  up to 3,473 add tokens but do not overflow a vocabulary.
  Expected lower bound for collisions was the repeated-title share: 23.33% of items
  (items whose title already appeared). Observed 69.91%: 46.58% of items collide with
  a different title -> limited resolution of RQ-KMeans 3x512 on these embeddings.
